# BOD

Automation of the daily BOD (Beginning of Day) routine for the Greeksoft UAT trading platform.

- [`bod-fetch/`](bod-fetch/) - stage 1: fetch the daily exchange/contract files (BSE, NSE, MCX) listed in the
  GreekSoft "Servers List with Configuration - BOD Files" sheet. See [bod-fetch/README.md](bod-fetch/README.md).

Not in this repo on purpose: the source documents (PDF/DOCX), `.env` credentials, the login browser profile and
downloaded files.
